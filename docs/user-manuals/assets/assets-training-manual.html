1. Learning goals

By the end of this session, you should be able to:

  • Open Asset Management and find the correct screen
  • Create Locations (and addresses) before bulk upload
  • Register an asset (form or Excel) and find it in All Assets
  • Issue an asset to an employee and read the assignment list
  • Return an asset (Good — Return To Stock / Outdated — Retire)
  • Know when to use DC Challan, Transfer, Maintenance, and Disposal
Access: You need Asset domain membership (IT and/or Non-IT). If Asset Management is missing from the module hub, ask a Superadmin. Sign in with your company account (Entra SSO or local admin credentials provided by the trainer).

3. Masters first — Types, Locations, Departments

Always configure masters before large uploads.

  1. Open Asset Types and confirm types you need (Laptop, Desktop, Monitor, etc.).
  2. Open Locations. Add a site (e.g. Greater Kailash, New Delhi). Optionally mark Head Office (only one per company).
  3. Select the location and add Addresses / buildings (e.g. Building A, CRC2).
  4. Open Departments if your process uses department ownership.
Important — Excel upload: Upload Asset List does not create locations. It only matches an existing location name. If the name is missing, import fails — add the location under Assets → Locations first, then use the same spelling in Excel.

4. Add assets & Excel upload

4.1 Add one asset (form)

  1. Go to Add Asset (or + Add from All Assets).
  2. Enter name, type, serial / tag, make, model, configuration.
  3. Pick location / address when prompted.
  4. Save — confirm the asset appears in All Assets as In Stock.

4.2 Bulk upload (Excel)

  1. Prepare Excel with columns such as asset tag, name, serial, make, model, type, and location (exact site name).
  2. Open the import / upload dialog from inventory.
  3. Map columns, review validation errors, then confirm import.
  4. Fix any “Location not found” rows by creating the location, then re-import.
Tip: Start with 2–3 test rows before uploading a full sheet during training.

5. All Assets — search, filters, detail

  1. Open All Assets.
  2. Search by tag, serial, name, or assignee.
  3. Use status chips / filters (In Stock, Assigned, Disposed, etc.).
  4. Open a row to view detail (overview, assignment history, location, accessories).
  5. From the row menu you can Assign, Return, Maintenance, Disposal, Portal, and more (by permission).

6. Asset Assignments — issue an asset

Screen title: Asset Assignments. Card title: Assigned Assets.

  1. Open Asset Assignments (or start Assign from All Assets).
  2. Click Add assignment / start the issue wizard.
  3. Select employee (Deployed-to), then asset(s) that are In Stock.
  4. Complete delivery / review steps and submit.
  5. Confirm the list shows Asset, Assigned, Employee ID, Assignment Date, Status, and DC Challan actions.
Assignment detail shows Asset, Assigned, Employee ID, Location, Assignment Date, and Status. Create DC from the list or detail when required by your process.
An open transfer (Draft / Submitted / Approved) can block assign or return on that asset. Cancel or complete the transfer first.

7. Return assets to stock

  1. From All Assets or Assignments, start Return for an assigned asset.
  2. Select return condition:
    • Good — Return To Stock → asset becomes available again (In Stock).
    • Outdated — Retire → route toward retirement / disposal process.
  3. Review and confirm. Verify status on All Assets.

9. Components & Documents

  • Components — chargers, batteries, accessories linked to a parent asset. Register shows Type, Parent asset, Status, Actions.
  • Documents — attach warranties, invoices, photos against an asset.

10. Common mistakes & FAQ

FAQ for trainees

QuestionAnswer
Upload failed: location not foundCreate the location under Locations first; match the Excel name exactly.
Cannot assign this assetMust be In Stock. Check for open transfer or active assignment.
Employee missing in Deployed-toEmployee must exist in HR / employee directory for the company.

  • Assign the asset to a demo employee
  • Open assignment detail and confirm key fields
  • Return the asset with Good — Return To Stock
